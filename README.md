<p>
  Lightweight XMPP server.
</p>

## version 1.x
 - based on Apache vysper 0.7
 - supports plain or TLS connections 
 - SASL authentication: PLAIN, DIGEST-MD5, SCRAM-SHA1 / SHA256
 - web-based managemnt panel (users, rooms, session, logs)
 - JSON-RPC API for integration and bots development purposes
